# CLI

Unter [./CLI](./CLI) liegt je CLI Befehl ein gleichnamiges File.
In der ersten Zeile wird der Name von `man $BEFEHL` eingetragen.
[[new_cli_note]] ist das Template für eine neue CLI Note.

# inbox

Unter [./inbox](./inbox) werden neue Notes abgelegt. Diese müssen noch einsortiert werden.

# systems

Unter [./systems](./systems) sind grundlegende Konzepte abgelegt. Zum Beispiel in [[cron]] wird die Notation gezeigt, welche für Cronjobs verwendet werden.

# templates

Unter [./templates](./templates) liegen die Vorlagen für unterschiedliche Notes.

# workflows

Unter [./workflows](./workflows) liegen längere Abläufe welche aus z.B. mehreren CLI Befehlen bestehen.
